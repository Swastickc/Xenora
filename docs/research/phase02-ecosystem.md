The Windows experiments provide design leads for host-side contracts. DirectXbox-Recomp targets original Xbox, and its NV2A behavior cannot establish Series RDNA behavior. PS5 and Xbox 360 have separate GPU and service contracts. Public AMD ISA and Apple or Microsoft API specifications are Class B for the behavior they document. Applying desktop RDNA semantics to Series is Class C. Repository source and developer reports do not elevate console claims or establish any authentic title milestone.

## Ranked experiments

The rank favors direct reuse of Xenora's existing test entry points and small, reversible changes. Each row proposes original Xenora code and fixtures under GPL-3.0-or-later. The source and root license for each design lead are pinned above. Independent reviewers derive expected values from public specifications or the original synthetic contract. Keep all probes isolated until review and leave each production interface on its current baseline if a probe fails.

| Rank and component | Scope, acceptance and fallback |
| --- | --- |
| 1. scarlett-layer differential compute case | Add one original integer/bitwise boundary case to the gfx1030 fixture and `tests/validation` flow, using the upstream ALU test shape. Compare lane-indexed outputs on the independent CPU path and native `crates/metal/tests/native_compute.rs`. Include a mutation such as a changed shift count that must alter a checked output. Risk is correlated expectations from the encoding helper or compiler. Derive expected words independently and retain the current fixtures if the case cannot distinguish the intended fault. [AMD RDNA2 ISA](https://www.amd.com/content/dam/amd/en/documents/radeon-tech-docs/instruction-set-architectures/rdna2-shader-instruction-set-architecture.pdf) |

Verify fixed-range overlap rejection, alias visibility through distinct guest addresses and rejection of a cross-boundary write with zero partial effects. Test guest permissions within a backing region larger than a guest page. Avoid fixed host mappings and signal handlers. Maintenance is limited to the original software map. Fall back to disjoint code and data regions if alias semantics are premature. [CPU boundary](phase02-cpu-feasibility.md) |
