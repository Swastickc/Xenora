# Middleware compatibility inventory

This directory records middleware-adjacent public interfaces and host technologies
that affect Xbox-game compatibility work. It is an evidence index, not a claim
that the corresponding middleware is implemented.

Start with [coverage.md](coverage.md). The table separates implemented behavior,
local verification, partial surfaces, unsupported behavior and research-only
notes. Entries must cite the existing detailed documentation or changelog evidence
instead of treating planned interfaces as coverage.

The same clean-room rules apply here as elsewhere in Xenora: only public or
authorized materials may be used; no leaked console SDK material, proprietary game
content or copied emulator implementation is admitted. Licensing boundaries are
part of compatibility design, especially for AMD FidelityFX and media middleware.
